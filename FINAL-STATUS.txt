# Writing Assistant Extension Starter

This session artifact is a working WXT + React browser extension starter for a writing assistant with:
- private local grammar heuristics
- selection-based rewrite actions
- popup controls for tone and settings
- background-service-worker message flow
- request throttling and debouncing
- gateway integration path
- PII redaction and sanitization logic
